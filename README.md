# Denisse Anne U. Dela Cruz — Portfolio

One-page VA portfolio. Plain HTML + Tailwind CDN, no build step.

## Preview locally

Double-click `index.html`, or from terminal:

```
start index.html
```

## Before deploying — fill in placeholders

- `index.html` line with `mailto:your@email.com` → replace with real email
- `index.html` line with `linkedin.com/in/yourprofile` → replace with real LinkedIn URL
- Profile photo: swap the SVG placeholder with a real `<img>` tag pointing to your photo

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. Go to vercel.com → New Project → import the repo
3. Framework preset: **Other** (static)
4. Click Deploy — done
